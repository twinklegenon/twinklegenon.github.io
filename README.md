# 📘 CPE 232 - Managing Enterprise Servers Portfolio

This project is a comprehensive portfolio showcasing the **hands-on activities, examinations, and learnings** from the **CPE 232 - Managing Enterprise Servers** course.  
It serves as a digital compilation of the **practical skills** acquired throughout the semester.

🔗 **Live Website:** [twinklegenon.github.io](https://twinklegenon.github.io/)

---

## 📂 Content Overview

The portfolio is structured around the course curriculum, covering a wide range of modern server administration and DevOps topics.  
Each section links to a detailed article outlining the objectives, steps, and outcomes of the activity.

---

## 🛠️ Key Topics Covered

### 🔹 Virtualization & Initial Setup
- Creating and configuring Virtual Machines (VMs)  
- Setting up SSH, including key-based authentication  
- Configuring different Linux distributions (Ubuntu, CentOS)  
- Git and GitHub for version control  

### 🔹 Configuration Management with Ansible
- Writing and executing ad-hoc commands and playbooks  
- Using **Ansible Roles** to structure and refactor automation code  
- Managing files, services, and packages across multiple nodes  
- Targeting specific hosts and using tags for granular control  

### 🔹 Enterprise Monitoring
- **Availability Monitoring:** Installing and configuring Nagios  
- **Performance Monitoring:** Installing and configuring Prometheus  
- **Log Monitoring:** Deploying the Elastic Stack (Elasticsearch, Logstash, Kibana)  

### 🔹 Containerization
- Building and managing Docker containers using a `Dockerfile`  
- Automating Docker image builds and container deployment with Ansible  
- Creating and running a sample web application inside a Docker container  

### 🔹 Cloud Infrastructure with OpenStack
- Automating the installation of OpenStack prerequisites (NTP, SQL, RabbitMQ, etc.)  
- Deploying core OpenStack services:  
  - Keystone (Identity)  
  - Glance (Image)  
  - Nova (Compute)  
  - Neutron (Networking)  
  - Horizon (Dashboard)  
  - Cinder (Block Storage)  

### 🔹 Examinations
- Solutions and documentation for the **Prelim, Midterm, and Final skills examinations**, integrating multiple course concepts.
